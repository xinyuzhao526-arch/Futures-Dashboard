# 商品期货市场结构看板

境内商品期货的市场结构研究面板。单文件 HTML，无外部依赖，ECharts 与样式全部内嵌，可直接静态托管。

**在线访问**：https://xinyuzhao526-arch.github.io/Futures-Dashboard/

## 当前版本

- 快照日期：2026-10-21（收盘结算口径）
- 覆盖品种：境内商品期货，剔除 5 个当日零成交品种后为 74 个，其中 66 个有席位排名
- 不含中金所金融期货（股指、国债）

## 页面结构

| 模块 | 内容 |
| --- | --- |
| 市场总览 | 多空分布、趋势中位数、名义净流、沉淀资金及占比、板块共振 |
| 趋势 × 拥挤度散点 | 横轴趋势评分 T（−100 至 100），纵轴拥挤度 C（0 至 100），气泡面积＝沉淀资金 |
| 板块矩阵 | 八个板块的多空广度、资金净额、三维确认与状态标签 |
| 品种明细 | 74 行静态表，含 T、C、资金流、持仓变化、席位净多比、换月次数 |

## 指标口径

**趋势评分**：`T = 100·tanh(0.8·(0.5·z20 + 0.3·z60 + 0.2·z120))`，其中 `z_k = k 日对数收益 ÷ (60 日日波动率 × √k)`。价格取复权后的主力连续结算价；单日对数收益绝对值超过 11% 判定为换月并归零，本次识别 46 处。

**拥挤度**：`C =（持仓量 250 日分位 + 成交持仓比分位 + 20 日波动率分位）÷ 3`。原设计为五项，席位净多分位与基差分位因缺少历史序列与现货价未纳入，因此**读数系统性偏低，应视为下限**。

**资金流**：名义净流 = 持仓量变化 × 结算价 × 合约乘数，已拆分量效应与价效应，持仓按单边计。合约乘数由「当日成交额 ÷（成交量 × 结算价）」反推，71 个品种全部落在整数且与交易所规格一致。

**三维确认**：趋势、资金、席位各为一维，每维可弃权（趋势 |T|≥20、资金流占沉淀资金 ≥0.3%、席位净多比 |N|≥3%），同向票数 0–3。

**席位**：净多比 `N =（前 20 多头 − 前 20 空头）÷（前 20 多头 + 前 20 空头）`，样本 66/74；缺原油、集运指数、铂、钯、原木、纤维板、胶合板、线材。结论只能读作「样本席位偏多」。

## 更新方式

重新生成同结构 HTML 后覆盖 `index.html`，页面内嵌的 `window.__DASH__` 携带全部数据，无需其他文件。

```bash
python3 deploy_project.py <owner>/<repo>
```

## 已知限制

- 拥挤度仅三项，缺席位历史与基差，读数偏低
- CFTC 非商业净持仓、LME 库存与注销仓单在境内无数据源，第四条主线缺失
- 4 个微型品种（原木、纤维板、胶合板、线材）沉淀资金低于 3 亿，读数不稳，不参与结论
- 参数（0.5/0.3/0.2 权重、tanh 系数 0.8、80 分位阈值）为本方案自定，非任何商业产品的方法论还原
